# Supermarket Sales Analysis & Business Intelligence

## Project Overview

An end-to-end supermarket sales analytics project using Microsoft Excel and Power BI.

The project covers data cleaning, preparation, exploratory analysis, KPI development, customer and product analysis, and interactive geographic and executive dashboards.

## Tools

- Microsoft Excel
- Power Query
- Power BI
- DAX
- PivotTables

## Key Results

- **Total Sales:** $2.26M
- **Unique Customers:** 793
- **Unique Orders:** 4,922
- **Average Revenue per Order:** $459.48
- **Highest Sales Year:** 2018 — $722,052.02
- **Highest Sales Month:** November — $350,161.71
- **Top Category:** Technology — $827,455.87
- **Top Sub-Category:** Phones — $327,782.45
- **Top Region:** West — $710,219.68
- **Highest-Value Customer:** Sean Miller — $25,043.05

## Project Workflow

Raw Data → Excel Cleaning → Excel Analysis → Power BI Data Preparation → Data Modelling → DAX → Interactive Dashboard → Business Insights

## Dashboard Pages

### 1. Executive Overview
Provides an executive-level view of sales, customers, orders, average revenue per order, yearly and monthly trends, regions, categories and segments.

### 2. Customer & Product Analysis
Examines top customers, top products, customer revenue concentration and sub-category performance.

### 3. Regional & Geographic Analysis
Examines state and city sales, geographic sales distribution and unique customers by state.

## Files

- `Supermarket Analysis.xlsx` — Excel data preparation and analysis
- `Supermarket Sales Dashboard.pbit` — Power BI dashboard template

## Skills Demonstrated

Data cleaning, data preparation, Excel analysis, PivotTables, Power Query, DAX, data modelling, KPI development, dashboard design, customer analysis, product analysis, geographic analysis and business intelligence.
